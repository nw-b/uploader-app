Privacy Policy

Last updated: November 6, 2026

AI Music Studio Uploader is a private tool run by its owner on their own computer to upload, schedule and check the status of videos on YouTube channels the owner controls.

Data accessed

With the account holder's permission, the tool uses the YouTube Data API to upload videos, set titles, descriptions, thumbnails and release times, and read the channel's own video list and statistics. It does not access any other Google data.

Storage and sharing

OAuth tokens and channel data stay on the owner's computer. Nothing is sold, shared with third parties or used for advertising. No data from other people is collected.

Revoking access

Access can be removed at any time from the Google Account permissions page (myaccount.google.com/permissions).

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Contact

Use the support email shown on the Google sign-in consent screen for this app.
